# Recall · AI 智能错题本

> 把零散错题变成可识别、可解释、可复习的学习闭环。

Recall 是一个本地优先的网页版 AI 错题本。它支持把文本或题目图片录入为结构化错题，通过 AI 讲解、变式练习和 SM-2 间隔复习，把“收藏过的错题”转化为每天可执行的复习队列。

当前为本地优先网页预览版：桌面和窄屏浏览器均可使用，数据保存在本机 SQLite 中；本版本明确不包含账号、云同步或跨设备数据一致性。

## 核心能力

### 录入与整理

- 文本录入：输入题目、答案和解析，AI 自动补全学科、知识点、错因、难度与题型。
- 识图录入：支持拖拽、点击选择和 `Ctrl+V` 粘贴截图；Qwen、GLM、Luna 并行识别，自动采用最快的两路有效结果交叉核对。
- 多题拆分：一张图片中的多道题可被自动拆开，导入前支持逐题检查、勾选和跳过重复题。
- 公式友好显示：常见积分、求和等符号转为易读形式，历史数据也会在渲染时兼容处理。
- 错题管理：支持按学科、错因、关键词、知识点和时间排序检索；支持相似题查看、确认后安全合并、受控字段批量编辑、保存筛选和 Markdown/PDF 导出。

### 学习闭环

- 今日复习：首页直接进入当天队列；逾期题优先，新题仅在当天补入，并支持每日负担上限。
- 学习处方与月历：首页给出薄弱知识点、连错/逾期预警和可点击补做日历。
- 错题重做：支持原题重做、AI 变式、分步骤输入、公式工具栏和手写图片批改；反馈含首处错误与下一步提示。
- SM-2 复习计划：普通重做、每日重做、变式和专题卷均通过统一入口更新掌握度、间隔和下一次复习日期。
- 卡片复习：提供 3 分钟卡片队列，支持翻面、键盘快捷键和四档自评。
- 考前专题卷：按考试日期、学科、逾期/掌握度/历史错误优先级可靠组卷，即使 AI 不可用也可用原题完成。
- 知识点讲解：从错题卡进入 AI 讲解，补足概念、易错点和方法。
- 举一反三：围绕原题生成同知识点的练习，避免只记住答案。

### AI 体验

- AI 对话：支持拍题、提问、追问、将题目加入错题本。
- 流式反馈：解答时持续展示分析、推导、复核等阶段，完成后逐段呈现内容；可主动停止生成。
- 数学题复核：复杂数学题优先完成推导和复核再呈现结论，降低中间错误干扰。
- 会话管理：新建、搜索、按日期分组和删除历史对话；切换页面时正在生成的回答保持运行。

### 数据反馈

- 仪表盘：显示今日复习、近期收录、快捷录入和学习概况。
- 数据看板：学习趋势、正确率、连续打卡、学科分布、规范化错因 Top、知识图谱和本地周报 MD/PDF 下载。
- 知识图谱：点击知识点即可跳转错题本并筛选对应题目。

## 快速开始

### 环境要求

- Windows 10/11
- Python 3.10+
- Node.js 18+
- npm 9+

### 1. 配置后端

```bash
cd backend
python -m pip install -r requirements.txt
copy .env.example .env
```

编辑 `backend/.env`，填写 OpenAI 兼容的 LLM 配置。默认示例为 DeepSeek：

```dotenv
LLM_API_KEY=your_api_key
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-chat
```

启动后端：

```bash
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Windows 环境也可以双击 `启动后端.bat`。该脚本当前使用本机 `D:\python3\python.exe`；如果 Python 位于其他路径，请修改脚本后再使用。

### 2. 启动前端

```bash
cd frontend
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:5173](http://127.0.0.1:5173)。Windows 环境可双击 `启动前端.bat`。

### 3. 验证服务

- 健康检查：[http://127.0.0.1:8000/api/health](http://127.0.0.1:8000/api/health)
- API 文档：[http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

## AI 与可选能力

| 能力 | 配置或依赖 | 降级行为 |
| --- | --- | --- |
| AI 归类、讲解、批改、变式题、对话 | `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL` | 保留本地录入和复习，部分 AI 功能不可用或退回基础逻辑 |
| Qwen / GLM / Luna 识图 | 在后端配置对应可用模型和凭据 | 识图任务提示失败，可改用文本录入 |
| Mathpix 数学 OCR | `MATHPIX_APP_ID`、`MATHPIX_APP_KEY` | 自动跳过 Mathpix，继续使用其他 OCR 候选 |
| 语义检索 | `sentence-transformers` | 使用关键词匹配 |
| 向量索引 | `chromadb` | 不影响基础错题管理与复习 |

> 当前 OCR 会并发尝试候选模型，并选择最快返回的两路成功结果。实际等待通常约 30-60 秒，图片清晰度、网络与模型响应会影响耗时。

## 使用流程

1. 从“识图录入”上传截图，或从“文本录入”手动填写题目。
2. 检查 AI 拆分和归类结果，勾选需要保存的错题。
3. 在错题本中查看解析，按知识点筛选，或进入“举一反三”练习。
4. 每天从仪表盘点击“开始今日复习”或“3 分钟卡片”，完成到期题目；逾期题会自动优先。
5. 使用“本周学习处方”进入专项补做，或在“举一反三”切换到考前专题卷。
6. 在看板中观察规范化错误类型、薄弱知识点和学习趋势，按需下载本周学习报告。

## 技术架构

```text
frontend/                         Vue 3 + TypeScript + Vite + Tailwind CSS
  src/views/                      仪表盘、错题本、录入、复习、看板、AI 对话等页面
  src/components/                 错题卡、Markdown/KaTeX、导航、知识点和几何工具组件
  src/api/                        Axios 请求封装与接口定义

backend/                          FastAPI + SQLModel + SQLite
  app/api/routes/                 REST 与 SSE 路由
  app/services/                   错题、复习计划、SM-2、识图、聊天、看板业务逻辑
  app/ai/                         LLM、OCR、向量检索与公式格式化
  data/                           本地 SQLite、图片、向量索引和运行日志
```

## 数据与隐私

- 错题、复习记录、笔记本、会话元数据默认保存于 `backend/data/`。
- 题目图片保存在本地数据目录。若启用云端 LLM 或 OCR，题目文本/图片会按相应服务的接口配置发送给该服务。
- 备份时请整体复制 `backend/data/`；恢复时应在服务停止后覆盖该目录。
- `backend/.env` 含密钥，不应提交到公开仓库。

## 已知边界

- 本版本不包含账号、云同步、局域网共享或跨设备一致性；备份请整体复制 `backend/data/`。
- OCR 的速度与稳定性依赖已配置模型及网络状态；数学复杂图片建议在导入前人工检查。
- AI 解答、归类与批改应作为学习辅助，重要结论仍建议结合教材、教师或标准答案复核。
- 图表、公式渲染和 PDF 生成已按路由/动作拆包；首次打开这些功能会加载相应资源。
