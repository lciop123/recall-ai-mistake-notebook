已知 f(x) = x³ − 3x + 1，求单调递增区间（变式：求单调递减区间）
你的答案：(−1, 1)
解析：f'(x)=3x²−3，f'(x)<0 得 −1<x<1，故单调递减区间为 (−1,1)。注意本题是变式题，问的是递减区间。
✗第 2 题答错
数列 {aₙ}：a₁=1，aₙ₊₁ = 2aₙ + 1，求通项公式（变式：a₁=2）
你的答案：aₙ = 2ⁿ　正确答案：aₙ = 3·2ⁿ⁻¹ − 1
解析：构造 bₙ = aₙ + 1，则 bₙ₊₁ = 2bₙ，b₁ = 3，故 bₙ = 3·2ⁿ⁻¹，aₙ = 3·2ⁿ⁻¹ − 1。变式题初始值变化后结果随之变化，注意不要套用原题公式。
