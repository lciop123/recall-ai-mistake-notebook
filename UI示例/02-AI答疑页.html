这道题为什么选 C？已知函数 f(x) 在 [a,b] 上连续，且 f(a)·f(b)<0，则下列说法正确的是……
这道题考察零点存在定理：若 f(x) 在闭区间 [a,b] 上连续且 f(a)·f(b) < 0，则至少存在一点 ξ ∈ (a,b) 使 f(ξ) = 0。

选 C 的原因：选项 C 说"函数在 (a,b) 内至少有一个零点"，这正是零点存在定理的直接结论。而 A 错在"有且仅有一个"——定理只保证至少存在一个，不保证唯一；B 错在区间端点取等；D 错在"有最值"与零点无关。

💡 易错点：连续 + 异号 → 至少一个零点，切勿把"至少"记成"唯一"。
